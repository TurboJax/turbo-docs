InvisPlaceholders is really simple and small.  
It's just used to hide the name of a player while they are in combat and have the invisibility potion effect.  

It requires both [PlaceholderAPI](https://modrinth.com/plugin/placeholderapi) and [PvPManager](https://modrinth.com/plugin/pvpmanager).  

## Placeholders:
| Placeholder | Description |
|-------------|-------------|
| `invisplaceholders_no_name` | Replaces the enemy's name with an empty string. |
| `invisplaceholders_fake_name` | Replaces the enemy's name with "Someone". |
