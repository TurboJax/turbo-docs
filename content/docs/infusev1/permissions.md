---
title: Permissions
description: All the permissions of InfuseV1
---

| permission          | default assignment | description                                  |
|---------------------|--------------------|----------------------------------------------|
| `infusev1.help`     | true               | Lets players use `/infuse help`              |
| `infusev1.reload`   | op                 | Lets players use `/infuse reload`            |
| `infusev1.revive`   | op                 | Lets players use `/infuse revive`            |
| `infusev1.setscore` | op                 | Lets players use `/infuse setscore`          |
| `infusev1.getscore` | true               | Lets players use `/infuse getscore`          |
| `infusev1.getscore` | op                 | Lets players use `/infuse getscore <player>` |
| `infusev1.give`     | op                 | Lets players use `/infuse give`              |
