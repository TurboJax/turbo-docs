# turbo-docs

This is a Next.js application made with [Fumadocs](https://github.com/fuma-nama/fumadocs).

## Development
Run development server:
```bash
npm run dev
# or
pnpm dev
# or
yarn dev
```

Then, open http://localhost:3000.
